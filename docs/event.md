# Event context

ATLAS was created for **Company Brain Hackathon: Build an AI Agent That Knows Your Organization**, presented by TechEquity Ai on November 4, 2026, at Snowflake's Silicon Valley AI Hub in Menlo Park, California. The event was part of the TechEquity Ai Monthly Forum Series.

## Challenge and ATLAS's response

The event describes a company brain as a knowledge system connecting company documents, processes, people, and internal tools for use by employees and AI agents. The Devpost submission brief asks for content uploaded into a company brain and used in a novel way.

ATLAS demonstrates this with fictional OrionCart checkout failures: users upload text or Markdown documents, retrieve role-scoped evidence from persistent memory, combine it with synthetic signals queried from a real local TriggerWare server, and generate a cited investigation and saved report.

## Technologies shared at the event

- [TriggerWare SDKs](https://github.com/triggerware/tw2-sdks): ATLAS uses the Python SDK and a fixed synthetic signals table.
- [Digo App Starter](https://github.com/digohq/app-starter): ATLAS reuses the shared OrgRole enum for demo editing capabilities. It does not deploy the full starter scaffold.

The event description lists Snowflake SVAI Hub and AI Alliance as sponsors and partners. Mention of an organization here describes event context, not an endorsement of ATLAS.
